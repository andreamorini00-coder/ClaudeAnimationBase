# reference/

Materiale di riferimento fatto fuori dal codice (per esempio con ChatGPT): mood board, model sheet, codici colore.
Le Fasi 3 (stili) e 4 (creatore di personaggi) partono da qui: prima si leggono questi file, poi si scrive il design.

| cartella | cosa ci va | serve a |
|---|---|---|
| `styles/` | mood board e palette per stile, una sottocartella per stile (`cozy/`, `anime/`) | Fase 3 |
| `characters/` | model sheet, viste, espressioni e colori per personaggio, una sottocartella per personaggio | Fase 4 |

Per ogni stile o personaggio conviene un file `note.md` con:

- i codici colore in esadecimale (`#RRGGBB`), con il ruolo di ciascuno (cielo, pelle, linea, ombra…);
- cosa prendere dalle immagini e cosa no;
- la fonte (strumento e prompt usati), se utile.

Immagini in PNG o JPG. Questi file sono riferimenti: il codice non li carica.
