# Stile anime — palette

| Colore | HEX | Ruolo |
|---|---|---|
| Avorio | #F7F2E8 | nuvole, luci chiare, carta |
| Giallo dorato | #FFD166 | tramonto, lampade, finestre (glow) |
| Corallo | #FF5D73 | accento forte, tramonto |
| Blu intenso | #427BEF | cielo diurno |
| Verde acqua | #3FAE9B | erba, vegetazione |
| Lavanda | #ADA2E8 | ombra delle nuvole, campiture secondarie |
| Viola ardesia | #555B91 | ombra unica e netta |
| Notte | #2B3766 | fondali e cieli notturni |
| Inchiostro | #1C2440 | solo contorni (mai nero puro) |
| Pesca | #F5C6A5 | pelle |
| Pesca ombra | #D99A86 | ombra della pelle |

Regole:
- Cel shading: colori piatti, una sola ombra netta (viola ardesia; pesca ombra sulla pelle).
- Contorno inchiostro, spessore costante, linee interne più sottili.
- Contorno e fondale notturno sempre diversi: il contorno deve leggersi anche di notte.
- Cieli al tramonto: niente gradienti continui, 2-3 fasce di colore (corallo, giallo, lavanda).
- Coni di luce dei lampioni: forme semitrasparenti di giallo dorato, non sfumature.
- Nuvole: forme a cumulo arrotondate, avorio con ombra lavanda.
- Le variazioni tonali dell'immagine sono solo atmosfera: in codice usare questi colori.
